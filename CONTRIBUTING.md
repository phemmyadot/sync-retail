# Contributing to Sync Retail

Thanks for helping. Bug reports, fixes, translations and features are all welcome.

## Before you start

- **Bugs:** open an issue with steps to reproduce, what you expected, and the app version (Admin → System, or the installer name).
- **Bigger changes:** open an issue first so we can agree on the approach. Feature plans live in [`docs/`](docs/); finished ones are in [`docs/done/`](docs/done/).
- **Security problems:** please don't open a public issue. Report them privately via GitHub's *Security → Report a vulnerability* on this repository.

## Development

See the README for running the app. Before opening a pull request:

```bash
npm run typecheck        # shared + backend + frontend
npm -w shared test       # pricing, tax, held sales, branding rules
```

Match the style of the code around your change, keep pull requests focused, and describe what you tested.
